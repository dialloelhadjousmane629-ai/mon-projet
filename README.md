# mon-projet

Site web en cours de développement.

## Description

Ce dépôt contient le code source du site : pages, styles et scripts.

## Structure prévue

- `index.html` : page d'accueil
- `css/` : feuilles de style
- `js/` : scripts
- `images/` : images et ressources

## Utilisation

1. Cloner le dépôt :
   ```
   git clone https://github.com/dialloelhadjousmane629-ai/mon-projet.git
   ```
2. Ouvrir `index.html` dans un navigateur.
